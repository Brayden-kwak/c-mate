18. State Rules (Do / Don't)

사용자가 다음 상태를 예측할 수 있도록 상태 표현을 고정합니다.

Do
  • primary는 화면 핵심 액션 1개에만 사용
  • 필수 미입력은 outline + inline error + toast
  • 삭제/손실 가능 액션은 danger 버튼 사용
  • 자동저장은 success chip으로 계속 표시
Do not
  • 저장하기와 다음을 둘 다 primary로 표시하지 않기
  • 아이콘 버튼을 aria-label 없이 두지 않기
  • 웹/모바일 필드 목록을 다르게 만들지 않기
  • 스타일 선택을 그룹별 5개로 오해시키지 않기
  • 모바일/compact FAB를 desktop frame 끝에 dock시키지 않기
  • 모바일 푸터에서 21px을 초과하는 전화번호/헤드라인 타입을 쓰지 않기
const STYLE_MAX_TOTAL = 5; const STYLE_GROUPS = ['appearance', 'personality', 'character']; function canSelectStyle(nextSelectedIds) { return nextSelectedIds.length <= STYLE_MAX_TOTAL; }
